# routeros_ip_service_webserver (Resource)
Enables or disables the individual parts of the built-in web server (WebFig, Graphs, REST API, CRL, SCEP, ACME) separately for HTTP (`www`) and HTTPS (`www-ssl`). A disabled part answers `403 Forbidden`. The port, allowed addresses and certificate are set with `routeros_ip_service`.

## Example Usage
```terraform
resource "routeros_ip_service_webserver" "settings" {
  webfig_plain = false
  graphs_plain = false
  index_plain  = false
  rest_plain   = false
  crl_plain    = false
  scep_plain   = false
  acme_plain   = false
}
```

## Schema

### Optional

- `acme_plain` (Boolean) Answer ACME HTTP-01 challenge requests at `/.well-known/acme-challenge/` over HTTP.
- `crl_plain` (Boolean) Serve certificate revocation list downloads at `/crl/` over HTTP.
- `graphs_plain` (Boolean) Serve Graphs at `/graphs/` over HTTP.
- `graphs_secure` (Boolean) Serve Graphs at `/graphs/` over HTTPS.
- `index_plain` (Boolean) Serve the home (login) page and static files such as `/favicon.png` over HTTP. Takes effect only when `webfig_plain` and `graphs_plain` are also `false`.
- `index_secure` (Boolean) Serve the home (login) page and static files such as `/favicon.png` over HTTPS. Takes effect only when `webfig_secure` and `graphs_secure` are also `false`.
- `rest_plain` (Boolean) Serve the REST API at `/rest` over HTTP.
- `rest_secure` (Boolean) Serve the REST API at `/rest` over HTTPS.
- `scep_plain` (Boolean) Serve the SCEP server at `/scep/` over HTTP.
- `webfig_plain` (Boolean) Serve WebFig at `/webfig/` over HTTP.
- `webfig_secure` (Boolean) Serve WebFig at `/webfig/` over HTTPS.

- `id` (String) The ID of this resource.
